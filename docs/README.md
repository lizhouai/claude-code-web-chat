# Project Documentation

This folder contains detailed technical documentation for the Claude Code Web Chat project (v1.1.0).

## Version 1.1.0 Updates

This documentation has been updated for version 1.1.0, which includes:
- Enhanced session management with improved synchronization
- Advanced MCP server health monitoring with automatic restart functionality
- Internationalization support for annotation system
- Improved visual feedback and user interface effects
- Enhanced folding functionality for better session management
- Optimized logo design and mode selection buttons
- Various bug fixes and performance improvements
