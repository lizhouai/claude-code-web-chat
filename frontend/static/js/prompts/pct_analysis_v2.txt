## HTML CODE FORMATTING REQUIREMENTS

**CRITICAL: Ensure proper line breaks in HTML code blocks:**

When generating HTML code blocks, follow these formatting rules:

1. **Use `<pre>` tag instead of `<div>` for code blocks**
2. **Preserve line breaks using actual newlines, not spaces**
3. **Each command should be on a separate line**
4. **Use empty lines between sections for better readability**
5. **Add proper CSS for code block rendering**

**Example correct format:**
```html
<pre class="code-block">
# Service Status Verification
sc query "Trend Micro Endpoint Basecamp"
sc query cloudendpointservice
sc query tmkmsnsr

# Network Connectivity Test
curl -v https://api-us-1.xbc.trendmicro.com/api/healthcheck

# Log Collection
powershell -ExecutionPolicy Bypass -File XdrEsDebug.ps1

# Process Monitoring
tasklist /svc | findstr /i trend
</pre>
```

**Required CSS for proper rendering:**
```css
.code-block { 
    background: #2d3748; 
    color: #e2e8f0; 
    padding: 15px; 
    border-radius: 5px; 
    font-family: 'Courier New', monospace; 
    overflow-x: auto; 
    white-space: pre-wrap;
    word-wrap: break-word;
    line-height: 1.4;
}
```

**DO NOT USE:**
- Single line code blocks without breaks
- `<div>` tags for multi-line code
- Spaces instead of actual line breaks
